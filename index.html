กำลังโหลดข้อมูล CVE…

ขอบเขตและข้อจำกัดของข้อมูล

การไม่พบข้อมูลแพตช์ไม่แปลว่ายังไม่มีแพตช์ และการมีแพตช์ไม่แปลว่าระบบของคุณแก้แล้ว ใช้ลิงก์ประกาศต้นทางตรวจรุ่นที่ใช้งานเสมอ

แจ้งเตือนทางอีเมล

อีเมลเป็นตัวเลือก ต้องตั้งค่าผู้รับและผู้ให้บริการส่งก่อนใช้งาน แจ้งเฉพาะ CVE ใหม่หรือความคืบหน้าสำคัญ ไม่ส่งซ้ำทุกรอบ การติดตามและแท็กบนหน้านี้อยู่ในเครื่องและไม่สมัครอีเมลให้โดยอัตโนมัติ

ตั้งรายการรับอีเมลแยกบนเซิร์ฟเวอร์ได้จาก CVE ID ที่ส่งออก ผู้ดูแลดูขั้นตอนใน คู่มือตั้งค่าอีเมล
